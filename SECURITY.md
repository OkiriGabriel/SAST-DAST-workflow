# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities privately to the repository maintainers. Do not open a public issue for exploitable findings.

If this template is used in another project, replace this section with that project's contact address and response timeline.

## Scanning

This repository runs SAST, DAST, and code scanning on pull requests and on a weekly schedule. Findings appear under **Security → Code scanning** and as workflow artifacts.
